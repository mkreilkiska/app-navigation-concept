# App navigation concept, prototype

One self-contained page: `index.html`. Open the GitHub Pages link on a desktop for the full prototype with its notes, or on a phone for the app mode (full screen, the pill; press and hold with two fingers for the prototype settings). Since 22.10. the page opens in Pill 2.0, the release after the design review; the toolbar's Release switch (desktop) and the Release row of the settings (phone, tablet) bring Pill 1.0 and the first release back, `?release=pill1` and `?release=first` preselect them, `?mono=russet` previews the Mono theme. The page is marked `noindex` and the site asks crawlers to stay away, but anyone with the link can open it.
